# 機構シミュレータ君

4節リンク、往復スライダークランク、4種類のカムを観察する学習アプリ。外部CSS・JavaScript・フォントは不要です。

## iPadでオフライン利用
1. HTTPSで公開したアプリをSafariで開きます。
2. 「オフライン起動の準備完了」を確認します。
3. 共有 → ホーム画面に追加。
4. 追加したアイコンから一度開き、準備完了を確認します。
5. 機内モードにして、アイコンから再起動します。

初回の取得には通信が必要です。サイトデータを削除した場合、端末が保存領域を解放した場合は再取得してください。iPadのファイルプレビューは実行方法として案内していません。

## 使い方
機構を選び、数値またはスライダーを調整して再生。速度・軌跡表示を変更できます。タッチやマウスで画面移動、ボタンで拡大縮小。設計は保存(JSON)で書き出し、読込で復元します。不正なJSONは設定を変更せず拒否します。

## 配布
ビルド不要。GitHub Pagesではmainブランチのルートを公開してください。`sw.js`、manifest、アイコンを含めて同じディレクトリに配置します。PC等ではindex.html単体もオフライン動作します。更新時はsw.jsのCACHEバージョンを変更してください。

## 通信とライセンス
入力データの外部送信、解析、広告はありません。Web版の初回取得・更新確認は同じサイトへの通信があります。ソースリンクを開く操作はGitHubへ移動します。外部CDN依存は除去しました。
